# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Harassment and personal attacks are not accepted.

Report unacceptable behavior to the maintainer through a [private security advisory](https://github.com/MiteshDhangar/beautify-alert/security/advisories/new) or by email to the address on the maintainer's GitHub profile. Reports are handled confidentially.
